# Seguridad
Este proyecto genera HTML a partir de datos del usuario (CSV y nombre del negocio). Toda entrada se escapa antes de insertarse en la pagina (anti-XSS) y los precios se manejan con Decimal.
Reporta vulnerabilidades abriendo un issue con la etiqueta `security` y sin datos privados. Alcance: solo este repositorio; no escanea ni accede a sistemas de terceros.
